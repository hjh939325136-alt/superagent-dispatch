# R1 本机只读状态

**简体中文** · [English](READONLY_STATUS.en.md)

在专用的 R1 演练环境中，由管理员运行安装器生成的 `manager-readonly` 入口。它固定使用该次安装的代码和服务账户，接收零个参数，返回一行有长度上限的 JSON。

查询使用固定账本，缺失账本会返回 `not_submitted`，并保持原状。成功响应包含任务状态、计划时间、请求模型、执行模式、token 用量和结果引用。错误返回固定代码。结果正文、原始配置、凭据和日志均保留在本机。

复现测试和演练范围见 [R1 安装演练](../m0_installer/README.md)。
