# 隔离 Hermes 候选对照

**简体中文** · [English](README.en.md)

模块用合成资料对照固定 Worker 与 Hermes 候选。对照固定上游 Hermes 0.16.0 的一个源码提交。Hermes 只通过 Unix socket 与可信 broker 交互。broker 检查请求、工具及真实回执，仅允许合成资料的搜索和读取。试验账本限制请求数并保留结果不明的预占。

如果完整响应和可信转发回执已经保留，可核对原任务、请求散列和租约后，结清同一个未知请求。账本恢复继续保留原审计，供应商重放为零。完整宿主会话恢复另行验证。

从源码根目录运行离线测试：

```sh
python -X utf8 -B -m unittest discover -s tools/m0_compare -t . -v
```

原生测试需要独立准备固定的 Linux Hermes 环境。公开模块使用合成配置和回执，实际供应商连接依赖另行配置的可信转发器和授权。试验入口独立于默认安装包。

开发对照使用 2 次 Worker 和 18 次 Hermes 真实请求。两边摘要均通过两轮，普通检索未交付。临时故障后两条当前版本读取成立，最终输出在 512 token 上限处截断。两轮服务端权限拒绝生效，拒绝说明仍需改进。保守预测门阻断了部分后续请求。当前结论适用于这组小样本。
